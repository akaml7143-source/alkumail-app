# الكميل

مشروع Flutter مستقل لتغليف واجهة الكميل الأصلية داخل تطبيق Android. يتم توليد Tailwind CSS وأيقونات Font Awesome محلياً أثناء بناء APK، ثم تُحزم داخل التطبيق. لا يحتاج التطبيق إلى اتصال إنترنت أثناء التشغيل.

## بناء APK عبر GitHub Actions

1. ارفع جميع محتويات هذا المجلد إلى جذر المستودع `alkumail-app` على الفرع `main`.
2. افتح تبويب Actions.
3. اختر `Build Al-Kumail APK` ثم `Run workflow`.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم `Al-Kumail-APK`.

اسم التطبيق على الهاتف: **الكميل**.
